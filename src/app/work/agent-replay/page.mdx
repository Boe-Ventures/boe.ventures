## The browser already knew

The original Agent Replay prototype came from a real frustration in AI-assisted web development. Coding agents were looking at screenshots while the browser held a much richer story: the click, the request it triggered, the 500 response, the console error, and the DOM change that followed.

The first thesis was broad: give agents structured browser data instead of pixels. Within months, Codex, Claude Code, Playwright, and Chrome tooling became excellent at live inspection. It would have been easy to quietly rewrite the old pitch or abandon the project.

I did neither. The exact April 2026 README and design are preserved in the repository, along with an unchanged Homi dogfood report that documented the original recorder's strengths and flaws.

## A sharper second vision

The part native browser tools do not solve is retrospective evidence. They are brilliant once an agent is attached. They cannot inspect the minutes that already disappeared.

Agent Replay is now a local, model-agnostic flight recorder:

> Capture once. Debug with any agent. Replay for humans. Export as video.

It records in rolling or deliberate session mode, writes a versioned local artifact, and exposes the same evidence in three forms:

## Trust before polish

The revival started by fixing the parts a recorder must get right. Events are UUID-addressed and monotonically ordered. Tabs and sessions cannot cross-write. The receiver binds to loopback, rejects hostile origins and malformed paths, limits batches and disk use, writes metadata atomically, and requires a token outside the local machine.

Safe privacy is the default: form values are masked, secrets are always removed, and only small same-origin text bodies are retained. Diagnostic and demo presets make the tradeoffs explicit.

## One artifact, three video paths

Stored rrweb events can be replayed after the fact and recorded with Playwright. Automated Playwright flows become annotated verification receipts with chapters and a structured step trace. The Chrome extension uses true tab capture and an offscreen MediaRecorder for high-fidelity marketing footage across navigation. Tab audio is opt-in beta.

WebM stays as the source. System FFmpeg creates H.264 MP4, GIF, posters, storyboards, and padded landscape, square, and vertical formats.

The distinction is honest: DOM reconstruction is excellent for ordinary web interfaces, but canvas, WebGL, maps, video, and cross-origin embeds need true pixel capture.

## Open and model agnostic

Flat files and the CLI are canonical. The MCP server has only five tools. Deterministic context budgeting makes the highest-signal evidence usable by smaller local models without spending another model call to summarize the recording first.

The package, extension, viewer, demo fixtures, marketing site, sample capsules, and receipts are all built in public.
